# Cleo Camp Studio Admin

Internal admin app for **Cleo Camp**, a small DTC apparel brand in Los Angeles.
It knows what's in the studio, notices what's running out, and says what to
order and when. The assistant layer inside it is **Studio Mouse**.

The people who use it are Cleo, Brandon, Jane and Nicki. Cleo is not technical
and checks it from her phone in the morning, which is why there is one
conversational surface rather than a set of forms.

## Running it

```bash
npm install
npx prisma generate
npm run dev
```

Environment variables are set by hand — never through a Vercel Storage
integration, for reasons in `CLAUDE.md` §1. Copy the key names from the Vercel
project; the values are not in this repo and must not be pasted into a
terminal.

Three things that have cost real time here:

- **Restart the dev server after `prisma migrate`.** It holds a stale client
  and returns the *old* shape without erroring.
- **Local runs use the real database and the real Resend key.** There is no
  staging copy of either. Set `EMAIL_DRY_RUN=1` before exercising anything that
  might send — two test emails have already reached real people this way.
- **`npx prisma generate` is not always automatic.** When a field you just
  added does not exist on the client, run it explicitly.

## Shape of the thing

```
app/(main)/        the screens — Home, Products, Components, Vendors,
                   Purchase orders, Wholesale, Finances, Inbox, To tend to
app/po/            the purchase order document, HTML and PDF
app/api/           chat, the two crons, inbound email, finances
lib/mouse/         Studio Mouse — prompt, tools, context, the nightly pass
lib/integrations/  Shopify (live, writing), calendar, QuickBooks (dormant)
lib/po-pdf.tsx     the real PDF a vendor receives
prisma/            schema and migrations
```

## The one rule worth repeating here

**Shopify is the permanent master for finished-goods inventory.** This app
writes through to it and never keeps a parallel count. Everything else in
`CLAUDE.md` §3 follows from that.
